# תפריט מסעדת השלום

תפריט דיגיטלי Mobile First שנבנה עם React ו־Vite.

## הרצה

```bash
npm install
npm run dev
```

## עדכון תוכן

- פרטי המסעדה נמצאים ב־`src/data/restaurant.js`.
- כל הקטגוריות והמנות נמצאות ב־`src/data/menu.js`.
- תמונות המנות נמצאות ב־`public/images/dishes`.
- כדי להוסיף תמונה למנה, מחליפים את `image: null` בנתיב לדוגמה: `image: "/images/dishes/kebab.jpg"`.

האתר מוגדר כרגע להצגת תפריט ללא מחירים.


https://peace-restaurant-menu.vercel.app/
